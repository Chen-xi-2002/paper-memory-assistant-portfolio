# 文脉 · 论文记忆助手

一个本地优先的网页原型：把读过的论文、自己的笔记和关键证据片段保存下来，写作时用自然语言找回“哪几篇论文支持这个观点”。

## 已实现

- 导入 PDF、TXT、Markdown，自动提取可复制文字作为全文检索源
- 手动录入论文元数据、摘要、读后笔记和证据片段
- 按标题、作者、主题标签、笔记、标注和全文分别加权检索
- 对话回答逐条附上论文、依据类型和匹配片段
- “智能联网”模式会在本地证据不足或用户明确要求找论文时，查询 OpenAlex 和 Crossref
- 支持基于上一轮引用的论文继续追问，例如“除了 French 之外还有哪些语言出现 stress deafness？”
- 在线候选会显示题目、作者、年份、摘要、DOI、被引数和开放 PDF 状态
- 可一键把候选元数据加入文献库；有开放 PDF 时可直接尝试下载和提取全文
- 在线只有元数据、没有全文时会标记“待补 PDF”，并给出来源链接或学术搜索入口
- 点击论文详情后，可以直接输入中文或英文问题，在整篇 PDF 全文中做“有 / 没有”查证
- 全文命中会返回相关句子和上下文；如果只有摘要，会明确提示不能判断正文
- 点击引用查看论文详情，并继续补笔记
- 全部本地数据保存在浏览器 IndexedDB 中
- 支持 JSON 导入与导出备份

当前本地问答使用的是词法检索和来源片段，不依赖云端大模型。在线检索使用公开学术接口，不需要 API Key；联网搜索词会发送给 OpenAlex 和 Crossref。若接口限流或浏览器阻止跨站读取 PDF，程序会自动降级为“给出题目和链接，等你手动导入 PDF”。

## 启动

在 macOS 上双击 `start.command`，或在本目录运行：

```bash
"/Users/chenxiping/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3" server.py
```

浏览器会自动打开 `http://127.0.0.1:8765/`。

不要直接双击 `index.html` 使用：PDF.js 和 ES Module 需要在本地服务器环境中加载。

## 数据说明

首次启动会载入 6 篇用于演示的文献，它们会显示“演示”标记。演示笔记是为了展示检索交互而写的概述，不是论文原文，也不应直接作为引用。导入真实论文后，可在论文详情中删除演示条目。

浏览器数据与具体浏览器、站点端口有关。建议定期使用“导出资料”备份。清除浏览器网站数据会同时删除文献库。

## 全文查证怎么用

在文献库打开一篇带有“全文可检索”标记的论文，在“在这篇论文里查证”中输入问题，例如：

> 粤语和汉语在感知英语重音时有什么差异？

系统会做中英文术语扩展（粤语 → Cantonese、汉语 → Mandarin/Chinese、重音 → lexical stress、感知 → perception），再检索已保存的 PDF 全文，返回命中的原句、上下文和关键词数量。

也可以直接在对话里问：

> 《论文标题》里有没有提到粤语和汉语在重音感知上的差异？

如果论文只有摘要，不会把摘要当成正文回答；如果关键词没有命中，也会明确说明“不能据此证明论文完全没有讨论”。

## 自动演示的数据说明

本机运行时，自动演示会从真实文献库复制已导入的 L1 Prosody 论文到独立演示库，因此可以展示真实的 PDF 全文和查证结果，不会修改原论文。

公开部署后，访客浏览器没有你本机的 IndexedDB，演示库不会自动包含这篇论文。正式发布前应选择以下方案之一：

1. 使用允许再分发的开放论文，并把全文作为演示数据发布。
2. 只发布元数据和摘要，全文由访客自行导入。
3. 制作一份明确标注为虚构的演示论文文本，避免版权和隐私问题。

不要直接把未授权 PDF 或全文打包进公开 Demo。

## 常见问题

### PDF 导入时报 `Setting up fake worker failed`

这不是 PDF 文件损坏，而是本地服务器已经停止。PDF.js 在解析时才加载 `pdf.worker.mjs`，如果运行 `server.py` 的终端被关闭，浏览器就无法再访问 `http://127.0.0.1:8765/`。

处理方法：

1. 双击 `start.command` 重新启动服务器。
2. 保持打开的终端窗口不要关闭。
3. 刷新论文助手页面，再重新导入 PDF。

新版程序会把这个错误显示成“PDF 解析服务没有连接”，不再只显示底层 worker 报错。

## 在线检索如何工作

1. 先在本地文献库中检索，并保留上一轮引用的论文作为对话上下文。
2. 如果问题明确包含“找论文 / 搜索 / 除了 / 跨语言 / 其他语言”，或者本地没有匹配证据，就生成适合学术数据库的英文检索式。
3. 同时查询 OpenAlex 与 Crossref，按标题、摘要、出版信息和被引数合并、去重、排序。
4. 有开放 PDF 时提供“尝试导入开放 PDF”；浏览器跨站限制导致失败时，元数据仍会保存，并标记待补 PDF。
5. 只有摘要时，只根据摘要中明确写出的语言、月龄或结论回答；没有直接证据时明确说不足以回答。

自动演示的推荐顺序是：搜索论文并保留题目、摘要和下载入口，导入 PDF 全文，阅读并添加笔记，搜索写作问题，最后进入单篇论文全文查证。
