# 论文记忆与引用助手 PRD

> 版本：v0.1（个人项目初稿）  
> 产品形态：本地优先的 Web 应用  
> 项目角色：AI产品经理 / 原型搭建  
> 目标：帮助研究生在写作阶段找回读过的论文、笔记和可核对的引用依据

## 1. 项目背景

论文阅读和写作之间存在明显的记忆断层：

- 前期读了大量论文，笔记散落在 PDF、文档和聊天记录中。
- 写作时需要某个观点或证据，却想不起来自哪篇论文。
- 通用问答工具可能给出流畅答案，但无法稳定回到用户真正读过的原文。
- 现有文献管理工具偏重“存储和格式化引用”，对“基于个人笔记和全文的提问”支持不足。

### 核心问题

用户不是缺少论文，而是缺少一个能在写作时快速找回“谁说过、在哪说过、依据是什么”的个人证据系统。

### 初始假设

如果将论文元数据、读后笔记、关键原文片段和 PDF 全文存入同一个可检索空间，并让回答明确标注来源层级，就能降低查找文献和核验引用的时间。

## 2. 目标用户

### 核心用户

需要持续阅读论文并完成课程论文、开题报告或毕业论文的研究生。

### 典型用户特征

- 同时阅读 10 篇以上论文。
- 会做笔记，但笔记缺少统一结构。
- 写作时需要回找理论、研究方法、结论或相互矛盾的观点。
- 对引用准确性敏感，不希望 AI 编造文献。

### Jobs to be Done

- 当我需要写一个观点时，帮我找到读过且能支持它的论文。
- 当我记得“某篇论文提过重音/韵律/语言经验”时，帮我定位具体论文和原文。
- 当我的论文库没有相关证据时，帮我寻找候选论文，而不是直接编答案。
- 当我准备引用时，让我能逐条核对来源。

## 3. 产品目标与非目标

### 产品目标

1. 建立个人论文记忆库：论文、笔记、证据片段和全文统一保存。
2. 支持可追溯问答：每个回答都能回到论文、笔记或全文片段。
3. 支持证据不足时的主动扩展：查询公开学术数据库并返回候选论文。
4. 建立“有 / 没有”的证据边界：没有证据时明确不回答或提示待补 PDF。

### 非目标（当前版本）

- 不替代 Zotero 等专业文献管理工具。
- 不自动生成完整论文或伪造不存在的引用。
- 不承诺理解所有同义表达，当前版本以关键词和中英文术语扩展为主。
- 不处理扫描版 PDF 的 OCR。
- 不做多人协作和云端同步。

## 4. 核心场景

### 场景 A：建立论文记忆

用户上传 PDF，系统提取全文和元数据；用户补充读后笔记和关键证据片段。

### 场景 B：基于个人文献库提问

用户问：“哪些论文认为二语语言经验会影响语音感知？”  
系统返回相关论文、命中字段和可核对片段。

### 场景 C：针对单篇论文查证

用户问：“这篇论文里有没有提到粤语和普通话在英语重音感知上的差异？”  
系统在指定论文全文内检索，明确回答有 / 没有，并展示命中原句和上下文。

### 场景 D：文献库没有证据

用户问：“除了法语，还有哪些语言表现出 stress deafness？”  
系统先说明本地证据边界，再搜索 OpenAlex / Crossref，列出候选论文、摘要、DOI 和开放 PDF 状态。

### 场景 E：候选论文补全

用户选择在线候选论文，先加入元数据；如果能获取开放 PDF，则尝试提取全文，否则标记为“待补 PDF”。

## 5. 成功指标

以下为建议指标，正式写进简历前需要完成用户访谈和可用性测试，填入真实结果。

### 北极星指标

用户在 60 秒内找到至少一条可追溯的论文依据的比例。

### 核心指标

| 指标 | 定义 | 目标值 |
| --- | --- | --- |
| 核心任务成功率 | 用户完成“导入论文 → 提出问题 → 找到依据” | ≥ 80% |
| 找证据耗时 | 从提问到确认一条依据 | 从 5–10 分钟降至 ≤ 1 分钟 |
| Top-3 检索命中率 | 20 个问题中，正确答案出现在前 3 篇 | ≥ 80% |
| 引用可追溯率 | 回答中的依据能定位到论文 / 笔记 / 全文 | 100% |
| 无证据错误回答率 | 没有依据却给出确定性结论 | 0 |
| 首次激活率 | 首次使用 10 分钟内导入论文并保存至少一条笔记 | ≥ 70% |

### 护栏指标

- 不把摘要伪装成全文。
- 不把“关键词未命中”表述为“论文绝对没有讨论”。
- 在线检索失败时保留已获取的元数据或链接。
- 用户个人论文数据不默认上传到第三方服务。

## 6. MVP 范围与优先级

### P0：必须完成

1. 导入 PDF、TXT、Markdown。
2. 提取 PDF 可复制文字并保存全文。
3. 手动补充论文元数据、读后笔记和关键证据。
4. 按标题、标签、笔记、证据和全文加权检索。
5. 对话回答附带引用卡片和来源类型。
6. 指定单篇论文的全文查证。
7. 本地 IndexedDB 持久化和 JSON 导出。

### P1：增强核心体验

1. 在线查询 OpenAlex / Crossref。
2. 支持基于上一轮论文继续追问。
3. 在线候选一键加入元数据。
4. 开放 PDF 自动导入，失败时降级为“待补 PDF + 来源链接”。
5. 中英文术语扩展，例如粤语 → Cantonese、感知 → perception。
6. 证据不足时明确拒答并给出搜索入口。

### P2：后续规划

1. Zotero 同步。
2. 向量检索和重排。
3. PDF 划词批注与页码定位。
4. BibTeX / RIS 导入。
5. 写作草稿引用检查。
6. 用户自带 API Key 的生成式回答模式。

## 7. 功能需求摘要

| 模块 | 用户价值 | 关键需求 | 验收标准 |
| --- | --- | --- | --- |
| 论文导入 | 建立可检索记忆 | 支持 PDF / TXT / MD / JSON | 成功提取全文并显示字符数 |
| 笔记与证据 | 保留个人理解 | 添加笔记、片段、标签、页码 | 保存后能被检索 |
| 文献库 | 管理长期资料 | 搜索、查看、编辑、删除 | 可按标题、作者、标签、全文检索 |
| 对话问答 | 找回论点依据 | 返回来源和片段 | 每条依据可打开论文详情 |
| 单篇全文查证 | 判断信息覆盖 | 有 / 没有、命中原句、上下文 | 无全文时明确禁止判断正文 |
| 在线检索 | 发现库外研究 | 搜索、去重、排序、来源标注 | 展示题目、作者、年份、DOI、状态 |
| 候选入库 | 继续积累记忆 | 元数据加入、开放 PDF 导入 | 失败时保留元数据和手动导入路径 |
| 数据安全 | 降低隐私风险 | 本地存储、导出备份 | 用户可独立导出全部资料 |

## 8. 关键产品决策

### 决策 1：证据优先，不做无依据生成

回答优先返回用户真正保存的论文和片段。即使文字不够“像聊天”，也要保证来源可核对。

### 决策 2：区分来源层级

系统明确区分：

- 论文全文
- 用户笔记
- 标注证据
- 在线摘要 / 元数据
- 待补 PDF

### 决策 3：先本地，后联网

默认先查个人文献库；本地证据不足或用户明确要求搜索时，再查询公开学术数据库。

### 决策 4：在线候选不自动污染个人库

默认由用户决定是否加入候选论文，避免无关结果破坏个人知识库。

### 决策 5：单篇论文需要独立查证

文献库检索只能回答“哪些论文可能相关”，不能回答“这篇论文里有没有”。因此增加单篇全文查证，支持有 / 没有判断和原句展示。

## 9. 用户流程

详细流程图见 [USER_FLOW.md](./USER_FLOW.md)。

核心闭环：

1. 导入论文。
2. 保存笔记和证据。
3. 提出问题。
4. 先检索本地文献库。
5. 证据不足时在线扩展检索。
6. 返回带来源的回答。
7. 用户核对、补充笔记或导入 PDF。
8. 新内容进入下一轮检索。

## 10. 边界情况与错误处理

| 情况 | 产品处理 |
| --- | --- |
| 扫描版 PDF | 提示无法提取文字，需要 OCR |
| PDF 服务器断开 | 提示重新启动本地服务并刷新页面 |
| 在线 API 限流 | 保留搜索入口，不把失败解释为“没有研究” |
| 只有摘要 | 只允许基于摘要回答，并明确不能判断正文 |
| 关键词未命中 | 说明不等于论文没有讨论，建议换词 |
| 开放 PDF 无法跨站读取 | 保存元数据，提供来源链接，让用户手动导入 |
| 重复论文 | 按 DOI 或标题去重 |
| 页面刷新时请求未完成 | 恢复对话并提示重新发送问题 |

## 11. 验证计划

详细方案见 [VALIDATION_PLAN.md](./VALIDATION_PLAN.md)。

### 用户访谈

- 目标样本：5–8 名正在写论文的研究生。
- 重点问题：笔记如何保存、写作时如何回找、引用核验最耗时的环节。

### 可用性测试

- 任务 1：导入一篇论文并找到全文状态。
- 任务 2：提出一个需要引用依据的问题。
- 任务 3：判断某篇论文是否包含指定信息。
- 任务 4：在线找到一篇新论文并加入文献库。

### 检索基准

建立 20 个真实问题，人工标注正确论文。记录 Top-1 / Top-3 命中率和无依据回答率。

## 12. 版本迭代

### v0.1：本地文献记忆

解决论文、笔记和全文的保存与检索。

### v0.2：可追溯回答

增加证据卡片、来源层级和指定论文全文查证。

### v0.3：在线扩展检索

增加 OpenAlex / Crossref、候选论文、开放 PDF 和待补 PDF。

### v0.4：证据边界与体验修复

修复在线检索上下文、无全文误答、PDF worker 断开提示和中英文术语扩展。

## 13. 上线验收标准

- 用户可以独立完成论文导入、提问和来源核对。
- PDF 全文能够在刷新后继续检索。
- 单篇论文查证能返回“有 / 没有”和至少一条上下文。
- 在线检索失败不会影响本地文档回答。
- 导出文件可以重新导入并恢复论文、笔记和证据。
- 演示环境有 3 分钟视频，能覆盖导入、问答、全文查证和在线检索。
