# 用户流程

## 1. 首次使用：建立论文记忆

```mermaid
flowchart TD
    A[打开论文助手] --> B[导入 PDF / 文本]
    B --> C{PDF 是否可提取文字}
    C -- 是 --> D[保存论文、摘要和全文]
    C -- 否 --> E[提示扫描版或解析失败]
    D --> F[补充作者、年份和标签]
    F --> G[添加读后笔记]
    G --> H[添加关键证据片段]
    H --> I[进入可检索文献库]
```

## 2. 基于个人文献库提问

```mermaid
flowchart TD
    A[输入自然语言问题] --> B[识别问题意图]
    B --> C[检索标题、标签、笔记、证据和全文]
    C --> D{是否找到相关本地证据}
    D -- 是 --> E[按相关度列出论文]
    E --> F[显示来源类型和命中片段]
    F --> G[用户打开论文核对]
    D -- 否 --> H[提示本地证据不足]
    H --> I{是否允许在线检索}
    I -- 否 --> J[建议换关键词或补充论文]
    I -- 是 --> K[查询 OpenAlex / Crossref]
```

## 3. 单篇论文全文查证

```mermaid
flowchart TD
    A[打开一篇论文] --> B[输入具体问题]
    B --> C{是否保存全文}
    C -- 否 --> D[明确提示无法判断正文]
    D --> E[引导重新导入 PDF]
    C -- 是 --> F[中英文术语扩展]
    F --> G[全文关键词与上下文检索]
    G --> H{是否命中}
    H -- 是 --> I[回答“有”]
    I --> J[展示命中次数、原句和上下文]
    H -- 否 --> K[回答“关键词未命中”]
    K --> L[说明不等于论文完全没有讨论]
```

## 4. 在线发现新论文

```mermaid
flowchart TD
    A[本地证据不足或用户要求找论文] --> B[生成学术检索式]
    B --> C[并行查询 OpenAlex / Crossref]
    C --> D[按标题和摘要去重]
    D --> E[按相关性、年份和被引数排序]
    E --> F[展示题目、作者、DOI、摘要]
    F --> G{是否有开放 PDF}
    G -- 是 --> H[尝试自动导入全文]
    G -- 否 --> I[加入元数据并标记待补 PDF]
    H --> J{导入是否成功}
    J -- 是 --> K[进入全文检索]
    J -- 否 --> L[保留元数据和来源链接]
    I --> M[用户下载 PDF 后手动导入]
    L --> M
```

## 5. 核心页面结构

### 对话页

- 问题输入
- 本地 / 智能联网模式
- 本地证据引用卡片
- 在线候选论文
- 待补 PDF 状态

### 文献库

- 标题、作者、年份和标签
- 全文 / 摘要 / 元数据状态
- 搜索与筛选
- 单篇论文详情
- 全文定向查证
- 读后笔记和证据片段

### 导入页

- PDF / 文本 / Markdown
- 手动录入
- JSON 批量导入和导出
- 错误恢复提示
